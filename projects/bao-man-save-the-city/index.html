Bao Man: Save The city

A browser-based beat ’em up game prototype built with Codex. The project focused on recreating the feel of a 3D arena fighting game by analyzing existing game materials and rebuilding the core movement, combat, item, and stage interactions for the web.

To improve implementation accuracy, I built supporting tools such as a 3D character editor and map editor, then used them to tune character setup, stage placement, combat behavior, and gameplay details instead of relying on AI output alone.

Instead of treating AI as a one-shot solution, I used a divide-and-conquer workflow: separating the work into characters, textures, maps, animations, and gameplay behavior, then using AI assistance within each domain before integrating everything into a playable 3D browser game.
