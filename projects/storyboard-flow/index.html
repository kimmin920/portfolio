Built at Publ

An interactive node-based visualization of the service’s page and navigation hierarchy, built with React Flow. It provides a visual way to explore complex relationships between pages, pApps, and their navigation structure within the service.

Features

  • Custom Auto Layout — Recursively traversed the hierarchy to calculate subtree heights and dynamically position nodes with consistent spacing, preventing overlaps in complex page structures.
  • Hierarchical Path Highlighting — Used DFS-based traversal to identify ancestor nodes and automatically highlight the entire path from the root to the selected descendant.
  • Permission-aware Visualization — Visualized access permissions for Guest, Member, and Membership users through dynamic node and edge colors.
  • Default Flow Visualization — Clearly distinguished default navigation paths to make the service’s page and navigation structure easier to understand.
  • Interactive Storyboard Navigation — Highlighted related nodes and edges on selection and automatically centered the selected node within the viewport.
