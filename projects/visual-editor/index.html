Project

Visual Web Builder with Responsive Drag-and-Drop Layout Engine

Built at Publ

I worked on a production-grade visual web builder that allowed business owners to create and manage responsive pages without writing code. As the frontend TPM and core frontend developer, I contributed from the initial POC concept to the design and implementation of the editor experience, internal grid system, elastic component rules, reusable block system, and draft-to-publish workflow.

The editor supported drag-and-drop layout editing, resizing, multi-select, nested grouping, configurable content blocks, responsive desktop/mobile layouts, and data-driven page rendering.

Features

  • Led frontend-side planning and implementation as the frontend TPM and core contributor, from initial POC concept to production launch.
  • Designed and implemented the visual editor experience for business users to build responsive pages without code.
  • Built a custom responsive grid layout system supporting drag-and-drop positioning and block resizing.
  • Implemented separate desktop and mobile layout editing to support device-specific page composition.
  • Developed multi-select interactions using keyboard modifiers, enabling users to select multiple blocks and convert them into groups.
  • Built nested grouping logic, allowing groups to contain blocks or other groups while preserving layout constraints.
  • Implemented bounding-box-based group sizing, automatically calculating group dimensions from all nested child elements.
  • Created reusable and configurable content blocks such as text, image, rich text, Twitter/X embed, YouTube embed, carousel, list, and slide banner blocks.
  • Defined elastic component rules so blocks could adapt to different sizes, layouts, and configuration states.
  • Built editor-side configuration panels for managing block content, styles, and behavior.
  • Implemented data-driven page rendering, where published pages were rendered from user-defined layout and content configuration.
  • Supported draft-to-publish workflows so users could safely edit, preview, and publish changes to live pages.

Demo

Responsive Drag-and-Drop Layout Editing

Demonstrates the core layout editing experience, where users can drag, position, and resize blocks within a responsive grid system. The editor supports device-specific layouts, allowing pages to be composed differently for desktop and mobile screens.

Multi-Select and Nested Grouping

Demonstrates multi-select interactions using the Shift key, allowing users to select multiple blocks and convert them into a group. Groups can also be nested inside other groups, enabling more advanced page composition while keeping related elements organized.

Bounding Box-Based Group Controls

Demonstrates how grouped elements can be edited through bounding-box-based controls. When a group is opened, users can reposition and resize the elements inside it, while the group size is automatically calculated from the outer bounds of all nested child elements, including deeply nested groups.

Configurable Elastic Content Blocks

Demonstrates reusable and configurable content blocks such as text, image, rich text, Twitter/X embed, YouTube embed, carousel, list, and slide banner. Each block was designed as an elastic component that could adapt to different sizes, layout contexts, and configuration states. The editor also included configuration panels for updating block content, style, and behavior without directly editing code.
