Project

One Line (in progress)

One Line is a quiet personal bookshelf built around memories instead of reading stats. The core idea is simple: remember each book through the one sentence that stayed with you the most.

Rather than tracking pages, ratings, streaks, or long reviews, users save a single meaningful quote, optionally capture it from a page photo, and organize those one-line memories into a personal bookshelf.

Focus

  • Designed the product around one strong constraint: one book, one sentence, one memory.
  • Built a mobile-first bookshelf experience for adding, organizing, and revisiting meaningful quotes with minimal friction.
  • Kept the product intentionally analog by avoiding in-app AI features, while providing optional prompts for reflection and book visual creation outside the app.
  • Focused the experience on personal meaning and memory instead of completion, productivity, or recommendation mechanics.

The main lesson was that constraints can make a product more memorable. By asking users to save less, One Line helps them remember what mattered more clearly.
